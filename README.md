# Sales Data Analysis

A Python-based data analysis project that uses **Pandas** and **Matplotlib** to analyse sales transaction data and identify revenue trends across regions, products, and months.

## Project Overview

This project analyses a sales dataset containing information such as:

- Product ID
- Region
- Quantity sold
- Product price
- Date of sale

The project calculates revenue for each transaction and uses data aggregation and visualisation to identify sales performance and trends.

## Features

### Revenue Calculation

Revenue is calculated for each transaction using:

```python
Revenue = Quantity × Price
```

The calculated revenue is then added to the dataset as a new column.

### Revenue by Region

Sales are grouped by region to calculate the total revenue generated by each region.

A bar chart is created to compare regional revenue performance.

### Revenue by Product

The project calculates the total revenue generated by each `ProductID`.

This allows products with higher and lower revenue performance to be compared.

### Monthly Revenue Analysis

The sales dates are converted into datetime values and grouped by month.

The project calculates total revenue for each month and displays the results using a bar chart.

### Highest-Revenue Month

The project identifies the month with the highest total revenue using Pandas.
